# Security Policy

## Reporting Security Issues
This repository hosts research scripts, translation tables, and documentation. It does not run live services or handle user data.

However, if you discover a security vulnerability in the patch tooling scripts (such as command injection in patchers or unsafe file path traversals):

1. **Do not** create a public issue.
2. Report the vulnerability privately to the maintainers via GitHub Security Advisories or by contacting `sanixmon@gmail.com`.
3. Provide a clear description and reproduction steps.

We appreciate responsible disclosure and will address valid concerns promptly.
